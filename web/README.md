# 댓글 대필소 (웹)

claude.ai Artifact 로 게시해서 쓰는 단일 HTML 파일입니다.
글을 붙여넣으면 저장해둔 내 말투로 공감 댓글 후보를 써 줍니다.

- 게시본: https://claude.ai/artifact/CZSbNGe1MGYDWzuMJ7Rim6
- 소스: `댓글대필소.html` (HTML + CSS + JS 한 파일)

## 탭 구성

| 탭 | 하는 일 |
|---|---|
| 댓글 쓰기 | 글(또는 캡처)을 넣으면 감정·상황을 먼저 읽고, 서로 다른 각도의 댓글 후보를 뽑습니다 |
| 내 말투 | 캐릭터, 어투·거리감·텐션·이모지·길이, 금지어, 버릇 |
| 댓글 샘플 | 예전에 직접 쓴 댓글. 어미와 리듬을 여기서 가져옵니다 |
| 공통 멘트 | 글을 안 읽고도 달 수 있는 범용 멘트를 카테고리별로. 누를 때마다 앞에 나온 건 빼고 새로 뽑습니다 |

## 동작 방식

API 키가 필요 없습니다. 페이지가 Artifact 런타임의 두 기능을 씁니다.

- `sample` — 페이지가 Claude 에게 직접 물어봅니다. 응답은 JSON 스키마로 강제해서 파싱 실패가 없습니다.
- `db` — 말투 설정, 댓글 샘플, 카테고리별 공통 멘트를 서버에 저장합니다.

둘 다 못 쓰는 화면에서도 페이지는 뜹니다. `db` 가 없으면 `localStorage` 로 떨어지고,
`sample` 이 없으면 생성 버튼만 잠그고 나머지는 그대로 씁니다.
캡처 첨부는 `sample.limits().images` 가 있을 때만 켜지고, 없으면 그 자리에 이유를 적습니다.

## 고쳐서 다시 올리기

이 파일을 고친 뒤 같은 Artifact 에 다시 게시하면 링크가 그대로 유지됩니다.
게시할 때 `capabilities: {sample: {}, db: {}}` 선언이 필요합니다(기존 게시본을 갱신하면 자동으로 따라옵니다).

로컬 브라우저로 그냥 열면 `window.claude` 가 없어서 생성이 되지 않습니다. 레이아웃 확인용으로만 쓰세요.
