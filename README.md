# 여기어때 숙소 메인 사진 다운로더 (Windows)

숙소 주소를 넣으면 **내 PC에 설치된 Chrome**으로 숙소 페이지를 열고, 메인 갤러리를 한 장씩 넘기며
사진을 모아 `01, 02, …` 순서로 저장합니다. 객실 사진과 후기 사진은 받지 않습니다.

## 1. 처음 한 번만: 설치

1. **Python 설치**: https://www.python.org/downloads/ 에서 Windows용 Python을 받아 설치합니다.
   설치 첫 화면 아래쪽의 **"Add python.exe to PATH"를 꼭 체크**하세요.
2. **Google Chrome**이 설치되어 있어야 합니다. 이미 쓰고 계시면 그대로 두면 됩니다.
3. 이 폴더의 파일(`yeogi_photos.py`, `install.bat`, `run.bat`)을 PC의 원하는 폴더에 저장합니다.
   GitHub에서 받을 때는 초록색 **Code → Download ZIP** 후 압축을 풀면 됩니다.
4. **`install.bat`을 더블클릭**합니다. 필요한 패키지(playwright, pillow)가 설치됩니다.
   설치된 Chrome을 그대로 쓰기 때문에 브라우저를 따로 내려받지 않습니다.

## 2. 실행

1. **`run.bat`을 더블클릭**합니다.
2. 여기어때 숙소 주소를 붙여넣고 Enter를 누릅니다. 검은 창에서는 마우스 오른쪽 클릭으로 붙여넣을 수 있습니다.
3. 메인 사진 예상 장수를 넣고 Enter를 누릅니다(이번 숙소는 `14`). 모르면 그냥 Enter를 누르면 됩니다.
4. 끝나면 이렇게 표시됩니다.
   ```
   수집한 사진: 14장 (갤러리 표시: 14장)
   다운로드 성공: 14장 / 실패: 0장
   저장 위치: ...\downloads\숙소이름_86130
   ```

사진은 `downloads\숙소이름_숙소ID\01.jpg … 14.jpg`로 저장됩니다. 같은 폴더의 `manifest.json`에는
사진마다 실제로 받은 주소, 해상도, 확인된 후보 주소가 기록됩니다.

## 접속이 막히거나 갤러리를 못 찾을 때

- 처음에는 브라우저를 화면에 띄우지 않고 실행합니다. **접속이 막히면 Chrome 창이 자동으로 뜹니다.**
  창에서 직접 접속이나 인증(로그인, 보안문자 등)을 마치고 숙소 페이지가 보이면,
  검은 창으로 돌아와 **Enter**를 누르세요. 작업이 이어서 진행됩니다.
- 갤러리를 자동으로 열지 못해도 Chrome 창이 뜹니다. 숙소 상단의 메인 사진을 클릭해
  갤러리를 직접 열고, 첫 번째 사진이 보이면 Enter를 누르세요.
- 이때 쓴 로그인이나 인증 상태는 `chrome_profile` 폴더에 저장되어 다음 실행에도 이어집니다.
  평소 쓰시는 Chrome 프로필과는 별개입니다.
- 처음부터 브라우저 창을 보면서 실행하려면, 명령 프롬프트에서 이 폴더로 이동한 뒤 다음처럼 실행하세요.
  ```
  run.bat "숙소주소" --expected 14 --show
  ```

## 동작 방식

- **주소를 추측하지 않습니다.** 갤러리 안에 실제로 있는 `<img>` 요소(`src`, `srcset`)와,
  브라우저가 실제로 받은 이미지 응답에서 확인된 주소만 사용합니다.
- **메인 사진만 받습니다.** 수집 대상은 메인 갤러리 창 안의 사진뿐이라, 페이지의 객실 사진과
  후기 사진은 포함되지 않습니다. 네트워크 응답은 갤러리에서 찾은 사진의 다른 크기 버전을 찾는 데만 씁니다.
- **가장 큰 해상도로 저장합니다.** 같은 사진의 크기별 주소를 모두 받아본 뒤, 픽셀 크기가 가장 큰 것을 저장합니다.
- **중복을 제거합니다.** 주소와 실제 파일 내용 양쪽을 기준으로 같은 사진은 한 번만 저장합니다.
- **다운로드도 브라우저 세션으로 합니다.** 쿠키와 인증 상태를 그대로 사용합니다.

## 옵션

| 옵션 | 설명 |
|---|---|
| `--expected 14` | 예상 장수. 수집한 장수와 다르면 경고를 표시합니다 |
| `--show` | 처음부터 Chrome 창을 띄워서 실행합니다 |
| `--out 폴더` | 저장할 상위 폴더 (기본: 이 폴더의 `downloads`) |
| `--channel msedge` | Chrome 대신 Edge를 사용합니다 |
| `--chrome-path 경로` | Chrome 실행 파일 위치를 직접 지정합니다 |
