# 공감 댓글 생성기

글을 붙여넣으면 **내 말투로** 공감 댓글 후보를 만들어 주는 로컬 웹 앱입니다.
Claude(`claude-opus-5`)가 글의 감정과 상황을 먼저 읽은 뒤, 내가 등록해 둔 말투 설정과
실제 댓글 샘플을 따라서 후보를 여러 개 뽑아 줍니다. 마음에 드는 걸 골라서 복사하면 끝.

<br>

## 1. 설치

```bash
git clone <이 저장소 주소>
cd -

python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## 2. API 키 넣기

```bash
cp .env.example .env
```

`.env` 파일을 열어 `ANTHROPIC_API_KEY` 에 키를 넣습니다.
키는 <https://console.anthropic.com/settings/keys> 에서 발급받습니다.
(`.env` 는 `.gitignore` 에 들어 있어서 커밋되지 않습니다.)

## 3. 실행

```bash
python run.py
```

브라우저가 자동으로 <http://127.0.0.1:8765> 를 엽니다. 종료는 `Ctrl+C`.

<br>

## 쓰는 법

### 댓글 생성 탭

1. 상대방 글을 통째로 붙여넣습니다
2. **댓글 만들기** (또는 `Ctrl/⌘ + Enter`)
3. 맨 위에 "이 글을 이렇게 읽었다"(감정 / 상황 / 바라는 것)가 뜨고, 그 아래로 댓글 후보가 나옵니다
4. 마음에 드는 후보 → **복사**

후보마다 잡은 각도가 다릅니다(고생 알아주기 / 축하 / 그냥 들어주기 등).
글 하나에 대해 톤만 살짝 바꿔 다시 뽑고 싶으면 **이번만 말투 살짝 바꾸기**를 펼쳐서
어투·길이·텐션·이모지를 조정하면 됩니다. 이 조정은 저장되지 않고 그 요청에만 적용됩니다.

**이 말투 샘플로 저장** 버튼을 누르면 그 댓글이 학습 샘플로 들어갑니다.
쓰면 쓸수록 말투가 내 쪽으로 수렴하는 구조라, 마음에 든 결과는 눌러 두는 게 좋습니다.

### 말투 설정 탭 → `config/style.yaml`

| 항목 | 설명 |
|---|---|
| **내 캐릭터** | 모델이 가장 크게 참고합니다. "과장된 리액션 안 함", "구체적인 지점 하나를 짚음" 처럼 평소 스타일을 한 문단으로 |
| 어투 | 존댓말 / 해요체 / 반말 |
| 거리감 | 1(정중) ~ 5(절친) |
| 텐션 | 1(차분) ~ 5(리액션 크게) |
| 이모지 | 안 씀 / 가끔 / 자주 |
| 길이 | 짧게(1~2문장) / 보통(2~3문장) / 길게(4문장+) |
| **금지어** | 절대 쓰지 않을 표현. 모델에게도 금지시키고, 혹시 물고 나오면 결과에 ⚠ 경고가 붙습니다 |
| **필수 표현** | 가급적 포함시킬 표현. 빠지면 역시 경고가 붙습니다 |
| **그 밖의 내 습관** | 자유 서술. "물결표 안 씀", "느낌표는 한 개만" 같은 세부 버릇 |
| 공들이기 | `low` / `medium` / `high`. 높을수록 정교하지만 느리고 비쌉니다 |

웹에서 저장하면 `config/style.yaml` 에 기록됩니다. 파일을 직접 고쳐도 되고,
**서버 재시작 없이 다음 요청부터 바로 반영**됩니다.

### 내 댓글 샘플 탭 → `config/samples.md`

말투를 가장 정확하게 잡아주는 재료입니다. 예전에 직접 썼던 댓글을 넣어두세요.
**10~30개 정도 쌓이면 체감이 확 달라집니다.** 상대 글은 몰라도 되고, 댓글만 넣어도 됩니다.

<br>

## 이 앱이 지키는 것

말투만 흉내 내면 영혼 없는 댓글이 나오기 때문에, 프롬프트에 원칙을 박아 두었습니다.

- 글에 실제로 적힌 **구체적인 한 지점**을 반드시 짚습니다 (아무 글에나 붙는 댓글 금지)
- **묻지 않은 조언·훈수는 하지 않습니다**
- 내 경험담으로 화제를 가로채지 않습니다
- 감정을 단정하지 않고 "~겠어요", "~같아요"처럼 여지를 둡니다
- 후보끼리 시작 문구가 겹치지 않게 각도를 나눕니다
- **상실·부고·질병·사고·이별 같은 무거운 글**은 자동으로 감지해서 이모지·느낌표·밝은 리액션을 빼고
  톤을 낮춥니다. 이 규칙은 말투 설정보다 우선합니다

<br>

## 구조

```
run.py              실행 진입점 (서버 + 브라우저 자동 오픈)
app.py              FastAPI 라우트
comment_engine.py   프롬프트 조립 + Claude 호출 + 금지어 검사
store.py            style.yaml / samples.md 읽고 쓰기
config/style.yaml   내 말투 설정
config/samples.md   내가 쓴 댓글 샘플
static/index.html   웹 UI (단일 파일)
```

동작 방식:

1. `store` 가 말투 설정과 샘플을 읽어옵니다
2. `comment_engine` 이 이걸로 시스템 프롬프트를 조립합니다
   (요청마다 동일하므로 **프롬프트 캐시**를 걸어 두었습니다 — 반복 사용 시 입력 토큰 비용이 줄어듭니다)
3. JSON 스키마(`output_config.format`)로 응답 형식을 강제해 파싱 실패가 없습니다
4. 받아온 후보를 **금지어/필수 표현 기준으로 한 번 더 검사**해 경고를 붙입니다

## 참고

- 모델이 특정 글에 대한 응답을 거절하는 경우를 대비해 서버측 폴백
  (`server-side-fallback-2026-07-01`)을 켜 두었습니다. 계정에서 해당 베타를 쓸 수 없으면
  자동으로 일반 경로로 내려가므로 따로 손댈 건 없습니다.
- 서버는 `127.0.0.1` 에만 바인딩됩니다. 외부에 노출되지 않습니다.
- 포트를 바꾸려면 `.env` 의 `PORT` 를 수정하세요.
