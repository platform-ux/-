# 여기어때 사진 다운로더 (Windows 프로그램)

여기어때 숙소 링크를 넣고 **[다운로드]** 버튼만 누르면, 숙소 **메인 갤러리 사진만** 순서대로
`01, 02, …`로 저장하는 Windows 프로그램입니다. 객실별 사진과 후기 사진은 받지 않습니다.
파이썬 설치나 명령어 입력은 필요 없습니다.

## 프로그램 받기

1. 이 저장소의 **Actions** 탭 → **Build Windows exe** → 가장 위의 초록색 체크(✅) 실행 기록을 클릭합니다.
2. 아래쪽 **Artifacts**의 **YeogiPhotoDownloader-windows**를 눌러 zip을 받습니다.
3. 압축을 풀면 `YeogiPhotoDownloader.exe`와 `사용법.txt`가 있습니다.

사용 방법은 [`사용법.txt`](사용법.txt)를 보세요. 요약하면 다음과 같습니다.

- exe를 더블클릭 → 숙소 링크 붙여넣기 → [폴더 선택] → [다운로드]
- 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **[추가 정보] → [실행]**을 누르세요.
- 사이트가 보안 확인을 요구하면 Chrome 창이 뜹니다. 직접 확인을 마치고 안내창의 [확인]을 누르면 이어서 진행됩니다.

## 동작 방식

- PC에 설치된 **Chrome**(없으면 Edge)을 자동으로 조작합니다. 다운로드도 그 브라우저 세션(쿠키, 인증 상태)으로 합니다.
- 메인 갤러리를 열고 사진을 한 장씩 넘기며, **갤러리 안에 실제로 표시된 이미지**의 주소만 모읍니다.
  그래서 페이지의 객실 사진과 후기 사진은 포함되지 않습니다.
- 주소를 추측해서 만들지 않습니다. 페이지 요소(`src`, `srcset`)와 브라우저가 실제로 받은 이미지 응답에서
  확인된 크기별 주소를 모두 받아본 뒤, **픽셀 크기가 가장 큰 것**을 저장합니다.
- 중복 사진은 주소와 파일 내용 양쪽을 기준으로 걸러냅니다.
- 저장 폴더의 `manifest.json`에 사진별로 실제 받은 주소와 해상도가 기록됩니다.

## 개발자용

| 파일 | 내용 |
|---|---|
| `yeogi_gui.py` | 창 프로그램 (exe의 본체) |
| `yeogi_photos.py` | 브라우저 조작과 다운로드 핵심 기능. `python yeogi_photos.py URL`로 명령 프롬프트에서도 실행 가능 |
| `tests/make_mock_site.py` | 자동 점검용 가짜 숙소 페이지 (메인 14장 + 객실/후기 사진) |
| `.github/workflows/build-exe.yml` | Windows에서 exe를 빌드하고, 빌드된 exe로 가짜 페이지를 받아 보는 점검까지 자동 실행 |
